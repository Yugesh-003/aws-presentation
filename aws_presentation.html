Cloud 101

What is Cloud Computing?

Cloud computing is the on-demand delivery of IT resources — compute power, storage, databases, and applications — over the internet, with pay-as-you-go pricing.

  • No need to own physical hardware
  • Access resources from anywhere
  • Scale up or down instantly
  • Pay only for what you use
IaaS
PaaS
SaaS

☁️ Service Models

  • IaaS – Virtual machines, storage, networking
  • PaaS – Deploy apps without managing OS
  • SaaS – Ready-to-use software (Gmail, Slack)

AWS spans all three layers, giving you maximum flexibility.

AWS EC2

Amazon EC2 – Virtual Machines in the Cloud

Elastic Compute Cloud (EC2) provides resizable virtual machines (instances) in the cloud — like having a powerful server you rent by the hour.

  • Launch any OS: Linux, Windows, macOS
  • Choose from 400+ instance types
  • Pay per second (on-demand) or reserve for savings
  • Attach storage, configure networking, set security rules

Instance Families

  • General Purpose – t3, m6i (web apps)
  • Compute Optimized – c6i (batch, HPC)
  • Memory Optimized – r6i (databases)
  • GPU Instances – p4, g5 (AI/ML)
  • Storage Optimized – i4i (big data)

Auto Scaling

Scaling with EC2

↕️
Vertical Scaling Upgrade instance size (t3.micro → m6i.xlarge). More CPU & RAM for demanding workloads.
↔️
Horizontal Scaling Add more instances behind a Load Balancer. The AWS-preferred, highly available approach.
🤖
Auto Scaling Groups (ASG) Automatically launch/terminate instances based on CPU, request count, or custom metrics.

Scaling in Action

Imagine a flash sale on Amazon itself:

  • Demand spikes 10× in minutes
  • ASG detects high CPU → launches new EC2s
  • Elastic Load Balancer distributes traffic
  • After sale: ASG terminates extra instances
  • You only paid for the hours used ✅

AWS S3

Amazon S3 – Object Storage for the Internet

Simple Storage Service (S3) is AWS's flagship object storage. It was the first AWS service, launched in 2006.

  • Store any file: images, videos, backups, logs, datasets
  • Virtually unlimited storage capacity
  • 11 nines durability (99.999999999%)
  • Fine-grained access control with IAM & bucket policies
  • Hosts static websites, data lakes, ML datasets
